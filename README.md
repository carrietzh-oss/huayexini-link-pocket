# 花野链接夹

一个轻量、开源的浏览器链接收藏夹。看到以后还想回来的内容时，在 X、Instagram 或 YouTube 的单条博文/视频右上角点击紫色 `＋`，插件会保存这一条内容，而不是整个首页。

## 它做什么

- 在 X、Instagram、YouTube 信息流里识别单条博文或视频的永久链接。
- 自动保存标题、作者、正文摘要、视频/图片封面和来源平台。
- 根据内容关键词和媒体类型自动推荐六个分类；你也可以在弹窗里手动调整。
- 点击后提示“已保存到哪个分类”。
- 收藏卡片展示封面、标题、作者和内容说明，方便以后快速判断它是什么。
- 支持新建、改名、排序和删除分类。
- 在收藏夹里拖动卡片，即可移动到其他目录。
- 相同网址再次保存时更新原记录，不生成重复链接。
- 点击“打开原页面”直接回到收藏来源。
- 也可以在收藏夹页面手动粘贴一个链接。

如果你在信息流里看不到紫色 `＋`：

1. 在 `chrome://extensions/` 打开“开发者模式”。
2. 点击花野链接夹的“重新加载”。
3. 刷新已经打开的 X、Instagram 或 YouTube 页面。

默认分类包括：

- 待整理
- 需要体验的 AI 产品
- 需要阅读的内容
- 可参考的设计以及视频
- 可以落地的想法
- 好用 Prompt
- Web Coding Idea

## 安装（Chrome / Edge）

1. 点击 GitHub 页面右上方的 `Code → Download ZIP`。
2. 解压下载的 ZIP。
3. Chrome 地址栏打开 `chrome://extensions/`。
4. 打开右上角“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择解压后的仓库文件夹（里面能直接看到 `manifest.json`）。
7. 把“花野链接夹”固定到浏览器工具栏。

无需终端，无需 API Key。

## 使用

1. 打开 X、Instagram 或 YouTube 信息流。
2. 鼠标移动到目标博文或视频上。
3. 点击右上角紫色 `＋`。
4. 插件会识别单条链接、标题、作者和封面，并自动分类。
5. 点击弹窗底部“打开全部链接”，进入分类收藏夹。

## 数据和隐私

- 只在 X、Instagram、YouTube 页面运行，用于识别你主动点击的单条内容。
- 保存链接、标题、正文摘要、作者、封面地址、分类和你主动填写的备注。
- 不读取密码、Cookie、表单内容或私信。
- 不连接第三方 AI，也不会把收藏上传到服务器。
- 封面保存的是原平台图片地址，不会把图片文件上传到服务器；原平台地址失效后，卡片仍保留标题和原链接。
- 数据保存在浏览器扩展的本地存储中；卸载扩展会同时删除本地记录。
- 当前版本暂不连接 Obsidian。
